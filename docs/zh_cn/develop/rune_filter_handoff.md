## 当前目标

实现《魔灵召唤》符文仓库筛选：

- 只处理游戏内 `魔灵保管所 -> 符文 -> 管理` 页面。
- 使用 `127.0.0.1:5559` MuMu 模拟器；不要操作其他 ADB 设备。
- 第一版不接连续战斗结算。
- 需要本地 Web 页面自由配置筛选规则。
- 需要自动出售，但识别失败、已装备、已锁定、确认弹窗无法识别时必须保留或停止，不能误售。
- 效率计算参考公开 SWEX Rune Card 插件 `RaspFR/rune-card v1.2.1`。

## 分阶段强化筛选

- `agent/rune/upgrade.py` 实际按 `+6/+9/+12` 强化（`+0/+3` 都从 `+6` 起步），潜力搜索仍按 `+3/+6/+9/+12` 的副属性变化计算是否存在达到保留规则的可能路径。
- 稀有（蓝色）符文由 `sell-rare-quality-immediate` 最高优先级终止规则直接出售。`terminal=true` 的出售规则必须在 `analyze_upgrade` 中跳过强化路径搜索；装备、锁定和识别不完整保护仍在规则求值前执行。
- 猛攻/激怒/刀刃六号位命中或抵抗主属性只允许速度路径：无速度由 `sell-attack-slot6-acc-res-no-speed` 终止出售；未磨速度低于 21 时由专用分析返回全 SPD 路径；达到 21 才由 `keep-attack-slot6-acc-res-speed-target` 保留。扫描器每次实际强化后用 `attack_slot6_speed_deviated` 校验跨越节点数与最低速度增量，任何节点偏离即写入临时 `sell-attack-slot6-speed-deviated` 并出售；宝石速度不能参与该路径。
- 单条极品副属性独立于综合效率保留，使用未磨炼值判断：迅速/暴走/意志/无形速度 21+，其他套装速度 23+，暴击率 24+，暴击伤害 25+，体力/攻击/防御百分比及命中/抵抗 29+。这些阈值按当前账号尾部分布收紧；固定主属性四/六号位仍只接受速度 25+。
- 高优先级错配主属性规则中，猛攻二/四/六号位的体防、命中、抵抗主属性不再允许由速度副属性豁免，直接出售；迅速二号位体防主属性、祝福/守护/忍耐二/四/六号位攻击主属性仍只在没有速度副属性时出售。四/六号位任意主属性的传说符文若由更高优先级的专用高速规则命中仍可保留。
- 必定暴击输出规则覆盖迅速套装，不堆暴击率，但必须同时具备速度、暴击伤害和攻击力；二号速度、四号爆伤、六号攻击主属性分别由专用规则补足对应维度。
- 所有用途型保留规则均增加“有效强化次数”前置条件：根据品质、等级以及普通/远古六星副属性范围，结合已发生的强化总次数反推至少有多少次落在该用途相关属性上。默认至少 3 次；属性可以只集中在两项，但四次强化中有两次落到无关属性时不会通过。磨炼值不参与反推，已宝石替换属性不继承原属性的有效强化次数。通用高效率、单条极品和高速稀缺规则不重复套用此门槛。
- 第一轮用途筛选暂时将全部 `maxWithGrind >= ...` 门槛统一降为 `90`。方向由属性组合和有效强化次数负责，效率只作为宽松底线；应先预览各用途保留量，再逐组收紧，避免直接按高效率线误售方向正确的英雄符文。预设版本 `account-tuned-forodo-29649161-v3-progressive-max90` 会让旧 SQLite 内置规则自动迁移，同时保留启用状态和用户自建规则。
- `scan_rune_inventory` 的自动出售任务启用强化；每次强化后重新 OCR 详情并验证等级变化。
- 强化日志显示剩余节点、实际搜索状态数以及最多 3 条按最高单次强化值推演的可达规则路径；无路径出售时显示穷举结论和最多 3 个最接近规则的具体缺口。数值缺口必须同时展示当前值、`+12` 最佳值和剩余节点用途。例如英雄 `+6` 且只有 3 条普通副属性时，`+9` 可以强化已有属性，`+12` 必须揭示第 4 条普通副属性；先天属性不占普通副属性名额。不要打印全部组合，避免日志淹没单件符文结论。
- 六星传说迅速、暴走、意志符文只有先天属性达到天然最大值才作为洗炼胚子保留：普通符文暴击率 6、暴击伤害 7、效果命中 8；远古符文对应为 7、8、10。普通副属性不参与该规则；低于最大值、无先天或其他先天类型不命中。位置限制拆为三个规则组：1/3/5 号位不额外限制主属性；2 号位只接受速度主属性；4/6 号位排除体力、攻击力、防御力固定值主属性。新增默认组及旧版宽松条件会由 `merge_default_groups` 自动迁移到已保存的 SQLite 配置。
- 通用四号位暴击率/暴击伤害主属性规则不能只凭主属性和磨炼后效率保留。成品必须证明至少 3 次强化落在输出相关属性，并在速度、攻击%、体力%、防御%、暴击率、暴击伤害副属性中至少有两项达到门槛；必定暴击魔灵仍走独立的必暴输出规则。
- 绝望符文除高速命中控制外，也允许攻击输出路线：攻击%、暴击率、暴击伤害、速度均视为有效强化，至少证明 3 次有效强化且其中两项达到输出门槛。绝望同时属于“单条极品攻击/暴击/爆伤”的适配套装，避免连续强化到攻击%时因为缺少高速或命中而被误售。
- `calculate_efficiency` 同时返回原始 SWEX 效率和 `practical*` 实用效率。规则求值层会把已有的 `efficiency.current/max/maxHeroGrind/maxWithGrind` 字段统一映射到对应 `practical*` 值，因此内置规则和 SQLite 中已有的自定义规则都会将固定体力/攻击/防御副属性及其磨炼潜力按 50% 计算；速度及其他属性保持全权，固定主属性不减半。原始 SWEX 字段只用于日志、网页展示和外部兼容。
- 预览任务不实际强化，只统计建议强化数量。
- Web 服务不得自动打开浏览器。Maa 的 `Command` 动作不会把子进程 stdout/stderr 转发到用户可见日志，而且可能只把“进程已创建”当作成功；`SWRuneOpenWeb` 必须使用 `start_rune_web` Agent 自定义动作。该动作运行前台短生命周期启动器、捕获并转发输出，等待健康检查后打印实际访问地址 `http://127.0.0.1:<port>/`；没有地址或启动器非零退出时必须返回失败。平滑重启或切换备用端口时同样打印实际端口。
- 强化按钮、确认按钮、等级变化或详情 OCR 识别失败时停止任务，不盲点、不出售。
- 网格为空的判断必须先确认仓库无遮挡，并对同一格重试一次；确认空格后立即结束当前视图，不再点击后续坐标，改为三行翻页。连续两个翻页视图均无新符文时认为仓库结束，防止无限空翻。
